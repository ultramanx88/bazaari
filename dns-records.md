# DNS Records for Bazaari Mail Server

## Required DNS Records

### 1. MX Record
```
Type: MX
Name: @
Value: mail.bazaari.com
Priority: 10
TTL: 3600
```

### 2. A Record for Mail Server
```
Type: A
Name: mail
Value: YOUR_SERVER_IP
TTL: 3600
```

### 3. SPF Record
```
Type: TXT
Name: @
Value: "v=spf1 mx a:mail.bazaari.com ~all"
TTL: 3600
```

### 4. DKIM Record
```
Type: TXT
Name: mail._domainkey
Value: [Generated by setup script - see DKIM output]
TTL: 3600
```

### 5. DMARC Record
```
Type: TXT
Name: _dmarc
Value: "v=DMARC1; p=quarantine; rua=mailto:dmarc@bazaari.com; ruf=mailto:dmarc@bazaari.com; fo=1"
TTL: 3600
```

### 6. Reverse DNS (PTR)
Contact your hosting provider to set up reverse DNS:
```
YOUR_SERVER_IP -> mail.bazaari.com
```

## Testing

### Test SMTP
```bash
telnet mail.bazaari.com 587
```

### Test IMAP
```bash
telnet mail.bazaari.com 993
```

### Send Test Email
```bash
echo "Test email body" | mail -s "Test Subject" test@example.com
```

## Monitoring

### Check Mail Queue
```bash
docker exec bazaari-mailserver postqueue -p
```

### View Mail Logs
```bash
docker logs bazaari-mailserver
```

### Check Service Status
```bash
docker exec bazaari-mailserver supervisorctl status
```
